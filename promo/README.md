## 抖音文案 A（主推手机变麦）

旧手机别卖！扫码就能把手机变成 Mac 麦克风🎤

不用声卡，不用装 App，手机 / iPhone 都能当麦。
在家 K 歌：网易云、QQ 音乐、酷狗直接放伴奏，人声低延迟回放，音乐和人声统一输出。

开源免费，GitHub 搜 `mac-audio-hub`

## 抖音文案 C（主推多设备）

把 Mac 变成全家的 KTV 和音频中枢🎵

手机 → Mac 无线麦克风；
Mac → 手机 系统声音；
K 歌模式低延迟监听，8 台手机同时连。

旧手机别吃灰，扫码就能用。
GitHub 开源：`mac-audio-hub`

#桌面改造 #MacBook #K歌 #开源 #数码 #家庭娱乐

## 说明

- 延迟受 Wi-Fi、手机型号、输出设备影响，实测约 30–50 ms；
- 原唱 / 伴奏需要在网易云、QQ 音乐、酷狗平台内切换；
- iPhone 连续互通麦克风为实验性功能，需要 macOS / iPhone 的 Continuity 可用；
- 图中二维码指向 GitHub 仓库 `cpx734667-netizen/mac-audio-hub`。

# 使用手册

> 更完整的排错见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)，技术细节见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 1. 手机当麦克风

1. Mac 打开「Mac 音频枢纽」；
2. 手机与 Mac 连接同一个 Wi-Fi；
3. 手机相机扫描「麦克风」页二维码；
4. 首次打开会提示证书不受信任，这是本地自签名证书：
   - iPhone Safari：显示详细信息 → 访问此网站；
   - Android Chrome：高级 → 继续前往；
5. 手机点「开始传音」，允许麦克风；
6. 多台手机重复扫码，每台会自动分配通道；
7. 需要 Mac 本机麦克风时，打开底部「本机麦克风」开关。

保持手机页面在前台，锁屏或切后台会暂停麦克风。

## 2. Mac 系统声音送到手机

1. 切到「音箱」页；
2. 授予屏幕录制权限（见下）；
3. 手机扫描「音箱」页二维码，打开 `http://<Mac-IP>:8787/`；
4. 手机点「开始播放」；
5. 同一台手机重复打开时只保留最新连接。

### 屏幕录制权限

macOS 把「捕获系统音频」放在屏幕录制权限里。App 只取声音，不录屏。

1. 系统设置 → 隐私与安全性 → 屏幕录制；
2. 勾选「Mac 音频枢纽」；
3. 如果列表里没有，点左下角 `+`，选择桌面的 App；
4. 完全退出并重新打开 App；
5. 如果仍显示未授权，用 App 内的「重置旧授权」再添加。

> ad-hoc 签名重新构建后，旧授权可能失效，需要重新勾选。

## 3. K 歌

1. 在网易云 / QQ 音乐 / 酷狗里播放伴奏；
2. App 切到「K歌」页；
3. 手机扫码连接麦克风，点「开始传音」；
4. 点「统一音乐与人声」：
   - 将 macOS 系统输出与 App 人声输出同时切到内置/有线音箱；
   - 防止音乐在 JBL、人声在内置扬声器的错位；
5. 歌词：
   - 自动：系统 Now Playing 有歌名/歌手时尝试匹配 LRCLIB；
   - 手动：点「手动搜歌词」输入歌名/歌手；
   - 本地：点「载入 LRC」；
   - 对时：点「开始歌词」，用 ±0.5s 调整；
6. 原唱/伴奏在平台播放器内切换。

K 歌时不要用「Mac 音箱」给手机转发伴奏，它有约 300 ms 同步缓冲。

## 4. iPhone 原生麦克风（实验性）

Apple 官方的连续互通相机麦克风：

1. iPhone 与 Mac 登录同一 Apple Account；
2. iPhone 解锁，靠近 Mac，打开 Wi-Fi/蓝牙；
3. iPhone 设置 → 通用 → 隔空播放与连续互通 → 连续互通相机，开启；
4. Mac 系统设置 → 声音 → 输入，选择 iPhone（类型：连续互通相机）；
5. 等待 3 秒，App 麦克风页出现「iPhone 麦克风」；
6. 打开开关，允许麦克风权限。

如果 App 没有出现：

- 点「添加 iPhone 麦克风」打开系统声音输入设置；
- 确认系统里能看到 iPhone；
- 确认 iPhone 未锁屏、未低电量、未飞行模式。

该功能依赖 Continuity 状态，当前标记实验性。

## 5. 同时使用

- 手机 A：麦克风页面说话；
- 手机 B：音箱页面听 Mac 声音；
- Mac 本机麦克风 / iPhone 原生麦克风可与手机混音；
- 两个服务端口：8765（麦克风 HTTPS/WSS）、8787（Mac 音箱 HTTP/WS）。

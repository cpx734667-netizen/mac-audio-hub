# 排错手册

## 有杂音 / 断断续续

1. 输出切 Mac 内置扬声器，拔掉耳机/蓝牙，音量 70%，点「测试当前输出」；
2. 只保留一台手机，关闭本机麦克风，输入增益 50%；
3. 若只有 8787 有杂音，是系统音频捕获链路，不是麦克风；
4. 若测试音也有杂音：查耳机口/蓝牙/硬件/音量；
5. 若测试音干净、手机麦克风爆音：Wi-Fi 抖动或多路叠加。

当前构建已加入局部帧补齐、20/60 ms 抖动缓冲、20 ms 输出目标、软限幅和 DC 阻断。仍有持续底噪时，优先换内置/有线输出并录一段测试音。

## 手机麦克风没声音

1. 麦克风页「输出音箱」是否选了你正在听的设备；
2. 点「测试当前输出」；
3. 检查 Mac 系统音量、音箱音量、静音；
4. 如果输出是 JBL/蓝牙，换内置或有线；
5. K 歌时确认点过「统一音乐与人声」；
6. 手机页面是否在前台，是否锁屏。

## 手机显示已连接，但 Mac 电平为 0

- 手机端是否允许了麦克风；
- 手机浏览器是否静音了页面；
- 手机是否切到后台/锁屏；
- 尝试换 Safari/Chrome；
- 手机与 Mac 是否同一 Wi-Fi，能否打开 `https://<Mac-IP>:8765/health`。

## Mac 音箱没有声音

1. 屏幕录制权限是否勾选；
2. 授权后是否完全退出并重开 App；
3. 手机端是否显示捕获错误 / 0 帧每秒；
4. Mac 上是否有其他 App 正在播放声音；
5. 先用 App 的「测试当前输出」排除音箱问题。

## 屏幕录制权限反复失效

ad-hoc 签名的代码签名会随每次构建变化，macOS TCC 会视为新 App：

1. 系统设置中移除旧条目；
2. 点 `+` 添加当前 `Mac 音频枢纽.app`；
3. 勾选并重启 App；
4. 如需彻底重置：`tccutil reset ScreenCapture com.airmic.local`，再添加。

## iPhone 麦克风不显示

- iPhone 解锁、靠近、Wi-Fi/蓝牙打开；
- 同一 Apple Account；
- iPhone 连续互通相机开启；
- Mac 系统设置 → 声音 → 输入能看到 iPhone；
- 等待几秒，App 每 3 秒刷新；
- 点「添加 iPhone 麦克风」跳转系统设置。

## 音质像电话 / 很差

- 浏览器链路本身是 48 kHz / 16-bit 未压缩 PCM，码率不是瓶颈；
- iOS Safari 可能强制语音处理，网页不能完全关闭；
- 优先用 iPhone 原生麦克风；
- 输出用内置/有线，不用蓝牙；
- 手机靠近嘴，降低输入增益避免削波；
- 使用 5 GHz Wi-Fi。

## K 歌歌词不滚动

- 平台没有把 Now Playing 元数据交给 macOS；
- 手动搜歌词或载入 LRC；
- 点「开始歌词」用时钟对齐；
- 用 ±0.5s 调整。

## 原唱/伴奏不能切换

第三方 App 没有平台播放流/原唱接口。请在网易云/QQ/酷狗播放器内切换，或选择平台提供的伴唱版本。

## 构建失败

```bash
xcode-select --install
swiftc --version
```

要求 macOS 14+、Apple Silicon；查看 `build.sh` 输出中的第一个 error。
